계정 삭제 안내

라이프리오(LIFRIO) 계정과 관련 데이터는 앱 내에서 직접 삭제할 수 있습니다. 삭제 즉시 모든 데이터가 영구적으로 파기되며 복구는 불가능합니다.

중요: 유료 구독이 활성화된 상태로 계정을 삭제하면 남은 이용 기간과 미사용 CP(크레딧)는 자동 소멸되며 환불되지 않습니다. 구독·결제 환불이 필요한 경우 Apple App Store 또는 Google Play 환불 절차를 먼저 완료한 뒤 계정을 삭제해주세요.

앱에서 직접 삭제하는 방법

  1. 라이프리오 앱을 실행하고 로그인합니다.
  2. 하단 탭에서 마이 페이지로 이동합니다.
  3. 우측 상단의 메뉴(≡) 아이콘을 누릅니다.
  4. 화면을 아래로 스크롤해 하단의 "계정 탈퇴" 링크를 누릅니다.
  5. 삭제될 데이터 목록을 확인하고 "탈퇴 진행하기"를 누릅니다.
  6. 확인 입력란에 "탈퇴"를 정확히 입력한 뒤 "탈퇴 확정"을 누릅니다.
  7. 즉시 계정과 모든 데이터가 서버에서 삭제되고 로그아웃됩니다.

삭제되는 데이터

  • 계정 정보: 이메일, 소셜 로그인 식별자(카카오/네이버/애플 ID), 비밀번호 해시
  • 프로필: 닉네임, 학년, 전공, 관심분야, 목표 단계
  • 학습 기록: 콘텐츠 재생 위치, 완료 이력, 마지막 재생 시각
  • 자기이해 진단: 응답, 결과, 태그 스코어, 언락 이력
  • 회고(reflection) 기록 및 자동 수집된 활동 로그
  • CP(크레딧) 잔액 및 거래 내역, 획득한 업적·언락 기록
  • 좋아요·시청 기록, 광고 보상 이력, 출석 이력

보존되는 정보 (법령상 의무)

아래 정보는 관련 법령에 따른 보존 의무가 있어, 삭제 후에도 해당 기간 동안 이용자 식별 정보와 분리 저장된 후 파기됩니다.

  • 결제·환불 기록: 5년 (전자상거래 등에서의 소비자보호에 관한 법률)
  • 전자적 재화 공급 기록: 5년 (동 법률)
  • 소비자 불만·분쟁 처리 기록: 3년 (동 법률)
  • 접속 로그 기록: 3개월 (통신비밀보호법)

이 정보는 탈퇴 후 분리 저장되며, 라이프리오 서비스 이용이나 프로파일링에 재사용되지 않습니다. 보존 기간 경과 즉시 완전 파기됩니다.

자주 묻는 질문

삭제한 계정을 복구할 수 있나요?

아니요. 삭제는 즉시·영구적이며, 모든 학습 기록·구독·크레딧이 복구 불가능하게 파기됩니다.

삭제 후 같은 이메일로 다시 가입할 수 있나요?

네. 삭제 완료 후 같은 이메일로 새 계정을 만들 수 있지만, 이전 데이터는 복구되지 않습니다.

구독이 자동으로 취소되나요?

Apple App Store·Google Play 구독은 플랫폼 계정에 묶여있어 계정 삭제만으로는 자동 취소되지 않습니다. 각 플랫폼의 구독 관리 메뉴에서 별도로 취소해주세요:

  • Apple: 설정 → Apple ID → 구독
  • Google: Play 스토어 → 프로필 → 결제 및 정기 결제 → 정기 결제
